# SpawnCity: one-repository GitHub Pages cutover

**Only source and publisher:** [nostack-dev/spawncity-de](https://github.com/nostack-dev/spawncity-de). Its `main` builds game/Box3D/flight WASM; **this same repository's** `gh-pages` branch contains the standalone published site. There must be no second repository, mirror workflow, cross-repository deploy, or CDN.

## Verified blocker, 17 October 2026

- GitHub reports `has_pages=false` for `nostack-dev/spawncity-de`, `has_pages=true` for `ChristianHohlfeld/spawncity-de`.
- Repeated `POST /pages` and `PUT /pages` with `GITHUB_TOKEN` during real deploy failed **HTTP 403 Resource not accessible by integration**. GitHub Pages domain activation/migration must be performed once by a user with repository admin permission; no bot repository-content API can replace this.
- The current DNS/domain is attached to the former mirror repo. Keep its static site in place during migration (but disable its copying workflow). Do **not** delete it until the canonical site is serving the game through the custom domain and TLS.

## One-time handoff in GitHub Settings (must be performed by owner)

1. Open **[canonical Settings → Pages](https://github.com/nostack-dev/spawncity-de/settings/pages)**. Set **Build and deployment → Source → Deploy from a branch**, select `gh-pages`, directory `/(root)`, **Save**. This branch is fully generated by the canonical workflow and already exists. Confirm that GitHub Pages becomes enabled. If the existing `CNAME` file prevents initial setup due to the domain being claimed, perform step 2 before attaching the domain; don't change DNS to a nonworking site.
2. Open **[former mirror Settings → Pages](https://github.com/ChristianHohlfeld/spawncity-de/settings/pages)**. Remove **Custom domain: spawncity.de** from that repository. The mirror must not keep the domain reserved.
3. Return to **[canonical Settings → Pages](https://github.com/nostack-dev/spawncity-de/settings/pages)**. Set **Custom domain: spawncity.de**, Save; enable **Enforce HTTPS** once GitHub makes it available.
4. Verify `https://spawncity.de/build.json` contains the same 40-character SHA as the canonical repo's `gh-pages/build.json`, then the simulator/controller, HTTPS, game/changelog, audio and multiplayer. Verify root and mobile routes; rerun the canonical browser regressions. GitHub notes domain/DNS/certificate propagation can take time.
5. **Only after the above verified:** delete the former mirror repository `ChristianHohlfeld/spawncity-de` in its Settings → General → Danger Zone, or archive it temporarily if preservation is needed. Deletion is irrecoverable without restoring backup and is not required for the new site to work.

The apex DNS generally keeps GitHub Pages A-records; check current records before changing anything. Never edit DNS records on a guess, and do not remove the previous repo while it still hosts the active custom domain.

## Standard release path

Commit → all CI → canonical `.github/workflows/deploy.yml` builds fresh Box3D WASM and HTML → `gh-pages` commit **in the same repository** → GitHub Pages serves branch → live-domain browser and game regressions. A failed live-domain check must remain red, not be silently ignored.

No mirror, no second build/repo, no legacy `kurzlernen` build. Renderer migration is still **all or nothing**: no native/Three hybrid or fallback.
